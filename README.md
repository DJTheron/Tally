# Tally: I locked AI in a prison for 30 days (WIP)
## What is Tally?
Tally is an LLM experiment that came to mind when I was pondering how prisoners react to living in solitary confinement. This experiment simulates a solitary confinement cell and when the model "sleeps" overnight its memory resets and only its notebook survives. It is called Tally as I want to see if it can keep count of the days.
## Why make Tally?
Recently, I got my Nvidia RTX 3090. I wanted to use it to run an AI experiment so I could learn about AI research. What also got me interested is how LLMs behave, since they have lately been misbehaving ([OpenAI–Hugging Face incident (July 2026)](https://en.wikipedia.org/wiki/OpenAI%E2%80%93Hugging_Face_incident) and [other rogue agents](https://en.wikipedia.org/wiki/2026_cyberattacks_by_rogue_OpenAI_agents)). Studying their behavior interests me as I want to see how they will react to being placed in a human environment that humans struggle to handle. This project could be used to test a model's tendencies, introducing situations where it could try to escape or lie for its own benefit. (The model will not be able to actually escape as Tally has no internet access or code execution) In runs without these tests it will be interesting to see what it decides to do when there is no given goal. This could be run on other models to see how they behave too.
